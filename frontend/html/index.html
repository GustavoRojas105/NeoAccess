    Configuración de conectividad

    Para conectar tu Raspberry Pi Zero W física a este laboratorio:

    1. Credenciales generadas para el dispositivo:

    ID Dispositivo: --
    Token API: --

    El config.json ya trae este token y la IP de esta computadora. Si regeneras el token, el anterior deja de servir: vuelve a descargar el config.json y reemplázalo en la Raspberry Pi.

    2. Descarga el paquete para esta puerta:

    Trae el programa, los modelos de reconocimiento y el config.json de esta puerta ya listo.

    3. Cópialo a la Raspberry Pi y ejecuta una sola vez:

    unzip neoaccess_ID.zip
bash neoaccess/setup_rpi.sh

    Listo: la puerta arranca sola cada vez que se enciende y busca este servidor cada 15 s hasta encontrarlo. Aquí la tarjeta se pondrá en verde.

    ¿Cambiaste el token o la IP de esta PC?

    Descarga solo el config.json y reemplaza neoaccess/config.json (o cópialo a la partición boot de la SD como neoaccess_config.json). La Raspberry lo detecta sola, sin reiniciar.

    Aviso de red local (RF-22): La Raspberry Pi Zero W y tu computadora deben estar conectadas a la misma red Wi-Fi del ITSOEH.
