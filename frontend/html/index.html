Configuración de conectividad

Para conectar tu Raspberry Pi Zero W física a este laboratorio:

1. Credenciales generadas para el dispositivo:

ID Dispositivo: --
Token API: --

2. Descargar archivo de configuración automática:

Descargar config.json para Raspberry Pi

Guarda este archivo dentro de la carpeta raspberry_pi/ en tu Raspberry Pi Zero W.

3. Comprobar la conexión real ejecutando en la Raspberry Pi:

python3 test_conexion.py
Aviso de red local (RF-22): La Raspberry Pi Zero W y tu computadora deben estar conectadas a la misma red Wi-Fi del ITSOEH.
